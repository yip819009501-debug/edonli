五款趣味人格测试

解压后双击任一 HTML 文件即可离线运行，手机和电脑均适用。无需安装或联网。结果页可打印保存。

文件：ancient-role.html（古代身份）、love-personality.html（恋爱人格）、animal-personality.html（小动物人格）、soul-city.html（灵魂城市）、hidden-talent.html（隐藏天赋）。

每套 40 题，四个选项依次计入四个维度，各选中一次加 1 分。按最高分与次高分的有序组合匹配八种结果；并列时固定按维度顺序。结果含特点、理由、优势、彩蛋、传播文案和分数。仅供娱乐，不是心理诊断。
